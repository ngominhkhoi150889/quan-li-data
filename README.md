# Dữ liệu sổ chi tiêu chung

Kho này chỉ chứa dữ liệu cho ứng dụng [Sổ chi tiêu](https://ngominhkhoi150889.github.io/quan-li-chi-tieu/).

- Mỗi khoản chi là một issue đang mở. Tiêu đề issue là tên khoản chi.
- Phần mô tả nằm ở đầu nội dung issue; khối `<!--ledger:...-->` là dữ liệu số lượng và đơn giá do ứng dụng đọc.
- Đừng đóng hoặc xóa issue nếu vẫn muốn khoản chi xuất hiện trong sổ.

Ứng dụng đọc dữ liệu công khai. Muốn thêm khoản chi trực tiếp trong ứng dụng cần token GitHub có quyền `Issues: Read and write` trên kho này.
